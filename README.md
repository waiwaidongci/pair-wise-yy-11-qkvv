# hxyfront-62010 气瓶阀门适配器调度台

源提示词编号：5

潜水店气瓶充填前端系统。工作人员登记气瓶编号、容积、检验有效期、残压、目标压力、氧含量、氦含量、瓶阀螺纹、充填气体与清洁状态，由调度台统一分配阀门转接头。

## 调度规则

- **排队**：待充填瓶按「瓶阀螺纹 → 充填气体 → 清洁状态」排序，可按气体筛选；检验过期瓶沉底锁定。
- **占用互锁**：同一转接头在释放前不能分给第二瓶（FREE / BUSY / DIRTY 三态）。
- **清洁兼容**：高氧（EAN）与 Trimix 只能使用氧气清洁转接头；氧气清洁瓶接空气也必须用氧气清洁头。
- **污染路径**：氧气清洁转接头一旦接触空气瓶，充填完成后强制转入「待清洗」，清洗复位前不能再用于高氧 / Trimix；分配前二次确认。
- **完成签收**：填写操作员后完成充填，释放转接头并写入该瓶历史；未完成可拆回重新排队（同样记历史）。
- **过期保护**：检验过期瓶不得占用任何适配器。
- **持久化**：瓶、转接头、历史保存在 localStorage，刷新页面后队列与占用关系仍保留。
